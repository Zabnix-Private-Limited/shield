# SHIELD Design System

## Color Palette (From SHIELD Logo)
### Primary Colors
- **SHIELD Navy**: `#0F172A` - Used for main brand color, headers, text
- **SHIELD Blue**: `#2563EB` - Used for primary buttons, links, accents
- **SHIELD Green**: `#10B981` - Used for success states, checkmarks, positive indicators
- **SHIELD Light Blue**: `#60A5FA` - Used for hover states, secondary accents

### Neutral Colors
- **White**: `#FFFFFF` - Background
- **Light Gray**: `#F8FAFC` - Surface backgrounds
- **Gray**: `#64748B` - Secondary text
- **Dark Gray**: `#334155` - Body text
- **Divider**: `#E2E8F0`

### Semantic Colors
- **Success**: `#10B981` (same as SHIELD Green)
- **Warning**: `#F59E0B`
- **Error**: `#EF4444`
- **Info**: `#2563EB` (same as SHIELD Blue)

## Typography
- **Primary Font**: Inter (fallback: Roboto)
- **Font Scale**:
  - H1: 32px - Bold
  - H2: 28px - Bold
  - H3: 24px - Semi-Bold
  - H4: 20px - Semi-Bold
  - Body: 16px - Regular
  - Small: 14px - Regular
  - Tiny: 12px - Regular

## Brand Identity
- **Logo**: SHIELD with shield icon and tagline "Sahakar Healthcare Initiative to Exempt Lifestyle Disease"
- **Tagline**: 5000 Voices | 500 Handshakes
- **Design Principles**: Healthcare-first, minimal learning curve, mobile-first, fast workflows, enterprise design

## UI Components
### Buttons
- Primary: SHIELD Blue (#2563EB) background, white text
- Secondary: Light Gray (#F8FAFC) background, SHIELD Navy (#0F172A) text
- Success: SHIELD Green (#10B981) background, white text
- Warning: Warning (#F59E0B) background, white text
- Error: Error (#EF4444) background, white text

### Cards
- Background: White (#FFFFFF)
- Border: Divider (#E2E8F0)
- Shadow: Soft elevation

### Forms
- Input borders: Gray (#64748B)
- Focus state: SHIELD Blue (#2563EB) border
- Error state: Error (#EF4444) border

## Accessibility
- Minimum contrast ratio: 4.5:1 for text
- Support screen readers
- Support keyboard navigation
- Support font scaling
