## Interpretation

Where multiple references show different content density, preserve the common system:
- white/light surfaces
- teal brand
- dark navy text
- subtle borders
- rounded cards
- strong status semantics
- clear clickable rows
- adaptive responsive composition

Choose density according to viewport and workflow, not according to which screenshot happens to be open.
