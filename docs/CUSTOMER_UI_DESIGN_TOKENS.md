# Customer UI Design Tokens

Source: approved customer reference screens and `CustomerDesignTokens`.

- Canvas: light neutral; text: SHIELD navy; primary action: cobalt blue.
- Cash wallet: teal; reward points: amber; documents: purple; commerce: orange.
- Spacing scale: 4, 8, 12, 16, 20, 24, 32, 40.
- Control/card radii: 14 / 20 / 24; pill: 999.
- Motion: 140 ms feedback, 240 ms standard transition.
- Main header: menu, SHIELD lockup, live cash/reward chips, unread-notification badge.
- Subpage header: back action, title, contextual action only.

Tokens are presentation-only and never contain user or business values.
