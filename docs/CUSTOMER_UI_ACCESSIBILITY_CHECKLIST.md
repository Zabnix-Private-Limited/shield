# Customer UI Accessibility Checklist

- [x] Touch targets use Material controls or at least 44 px interactive height.
- [x] Main and subpage header actions expose tooltips.
- [x] Text truncates rather than overflowing in compact header chips.
- [ ] Verify semantic labels for each new card action and icon-only action.
- [ ] Verify 200% text scale on all customer screens.
- [ ] Verify keyboard traversal on web and screen-reader announcements for loading/error states.
- [ ] Capture contrast evidence for teal, amber, purple, and orange content.
