# SHIELD Android release notes

## Version

- Version name: 0.0.4
- Version code: 2026081401
- Release date: 2026-08-14

## Play Store "What's new"

Improved membership application status and membership-card handling.

Improved support-request updates, service booking, and preferred pharmacy/store changes.

Reliability, notification navigation, and security improvements.

## Release scope

This release includes the completed customer membership application lifecycle and related customer and agent/CRM source changes. It intentionally does not claim payment completion, issued membership cards, or device-notification delivery where the required live operational evidence remains separate from the app build.
